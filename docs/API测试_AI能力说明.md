# API 测试 AI 生成用例说明

> 本文说明接口列表批量入口和接口用例页面单接口入口的 AI 生成用例能力。接口导入、工作状态和用例确认以 API 测试产品说明与设计说明为准。

## 1. 能力边界

- 文件导入和 cURL 导入不调用 AI；文件导入可以按用户选择生成基础用例，但基础用例是根据接口定义生成的固定内容，不属于 AI 生成用例流程。
- 接口列表的“AI生成用例”和接口用例页面的“AI生成用例”是两个入口，共用同一套准备、生成、预览和保存流程。
- 接口列表入口支持批量选择已有接口；接口用例页面入口只接收当前打开的一个已有接口，生成范围固定，不允许在向导中扩展到其他接口。
- AI 只接收用户选定的已有接口，不负责解析接口文档、推荐接口或改变接口定义。
- 生成结果先进入临时预览，用户选择并保存后才写入正式用例。
- 保存后的 AI 用例状态为“待确认”，确认、调试和执行在用例管理中分别完成。
- AI 不自动创建执行集、不自动加入执行集、不自动发起请求。

## 2. 页面流程

```text
接口列表筛选或接口用例页面当前接口 → 五步向导选择接口 → 生成模式 → 生成中 → 预览确认 → 保存成功 → 用例管理确认
```

接口选择弹窗支持：

1. 按接口集多选，子接口集选择包含其后代接口集；
2. 使用“名称或 URL”统一搜索框按接口名称或 URL 筛选，并支持按接口状态筛选；
3. 按用例数筛选；
4. 服务端分页查询，默认 10 条，可切换 10 / 50 / 100；
5. 跨分页保留选择，并通过“全选当前筛选结果”获取服务端完整 ID 集合；
6. 变更筛选条件后清空已有选择，避免把不同筛选结果混在一起；
7. 点击下一步时展示实际选中接口数量。

从接口用例页面进入时，第 1 步只展示当前接口，并明确提示“本次仅针对当前选中的接口生成用例”；接口数量为 1 时不显示其他接口，也不能通过筛选改变生成范围。

如果已选接口中存在已有用例，继续前显示：

> 已选 X 个接口，其中 Y 个接口下已有用例，继续生成可能会生成重复的用例，确定继续 AI 生成测试用例吗？

向导第一步和第二步只修改本次操作草稿，不写入接口或已有用例。第 3 步自动展示生成中状态，生成失败时停留在当前步骤并支持返回调整或重试；生成完成后进入第 4 步预览确认，保存请求成功后才进入第 5 步保存成功。取消或关闭确认不会发起 AI 请求。

五步操作约定：

1. 选择接口：选择本次生成范围，点击“下一步”进入模式选择；
2. 生成模式：选择覆盖模式和模型，点击“开始生成”进入生成状态；可返回上一步调整接口范围；
3. 生成中：展示实时进度和耗时；生成失败时提供“上一步”和“重试生成”，生成中的请求不允许返回，避免中断中的预览状态；
4. 预览确认：查看统计卡片、预览并编辑用例，点击“保存新增用例”进入保存请求；可返回生成模式，重新生成当前范围；
5. 保存成功：仅在保存接口成功后展示“用例保存成功”，点击“完成”关闭向导；保存失败仍停留在第 4 步并保留重试入口。

## 3. 生成与保存规则

- 生成前按当前选择的接口数量估算批次数和预计用例数；实际生成按现有分批和流式流程执行。
- 已有用例不会被覆盖；保存时只追加用户选中的可保存结果。
- 生成前会提示所选接口下已有用例。保存时仍会按实际请求意图与已有用例、本次生成结果进行去重；已有用例存在时会跳过基础用例，重复名称会自动追加后缀。去重不会替换已有用例，用户仍可在预览阶段决定保存哪些结果。
- 生成失败或部分失败的结果保留在预览中，并显示失败信息，用户可重新处理。
- 保存前可以编辑生成结果；保存接口和用例时再次校验项目及接口权限。
- 接口编辑、普通用例编辑和 AI 预览编辑中的接口描述、用例名称、用例描述输入框均限制为 50 个字符，并显示字数提示。
- 每条新用例使用统一的运行字段和业务码断言结构，脚本写入请求覆盖内容，避免生成出不能执行的用例。
- 用例名和断言不因接口列表勾选或接口状态批量处理而自动变化。

## 4. 后端接口职责

| 能力 | 接口职责 |
| --- | --- |
| 生成准备 | 根据用户选定的接口 ID 建立临时预览，返回接口和已有用例数量。 |
| 预览用例查询 | 在当前预览内按关键词分页查询生成用例，支持跨页勾选。 |
| 生成计划 | 根据生成模式和接口范围返回批次及预计数量。 |
| 生成 | 调用统一 AI 服务，按接口批次写回临时预览，支持流式进度。 |
| 编辑预览 | 仅修改当前预览中的生成用例，不直接写正式数据。 |
| 保存 | 将确认选中的生成结果一次事务写入接口用例，并写入待确认状态。 |
| 丢弃 | 清理当前用户可见的临时预览，不影响接口、已有用例和执行数据。 |

所有管理接口遵循 `{code, message, data}` 响应结构，HTTP 状态码固定为 200；权限、模型额度、调用记录和错误提示由统一 AI 服务处理。

## 5. Prompt 与审计

- API 测试用例生成提示词位于 `backend/docs/prompt/api_generate_testcases.md`，业务代码只负责加载和传递。
- 两个入口共用接口用例生成能力标识；审计记录区分本次接口范围、批次、结果统计和失败原因，不记录 Token、Cookie、密码等敏感内容。
- 已下线的接口推荐分析、AI 智能导入及其提示词不再作为现行能力维护；历史审计记录仅保留可读展示。

## 6. 与接口状态、用例确认的关系

- 新增接口、请求定义变化接口和存量迁移接口的接口状态由文件导入或用户批量操作维护，AI 生成不会自动标记接口已处理。
- AI 生成并保存的新用例为“待确认”，原因是“AI生成”。
- 文件导入发现请求定义变化时，关联已有用例为“待确认”，原因是“接口定义发生变化”；用户填写的参数、断言、脚本和用例名称继续保留。
- 用户可以在用例详情中调整并确认用例；待确认状态不阻止加入执行集、调试或执行，确认只用于提醒和内容调整。
