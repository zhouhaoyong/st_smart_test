# 权限说明

## 1. 用户角色

| 角色 | 权限范围 |
| --- | --- |
| 超级管理员 | 使用平台 AI；管理平台用户、平台配置、全部公开和私有项目；执行平台数据治理和高风险操作 |
| 管理员 | 使用平台 AI；维护公共配置；管理公开项目内业务资产；管理本人创建的项目 |
| 普通用户 | 使用平台 AI；查看公开项目和本人创建的私有项目 |

### 1.1 角色与部门

部门只表示用户的组织归属，用于筛选、统计和业务展示，不自动授予任何角色。部门展示顺序为：测试部门、开发部门、产品部门、运维部门、其他部门。

- 用户自主注册后，默认是普通用户，与所选部门无关；
- 超级管理员在后台新增用户时，默认是普通用户，可以明确选择普通用户、管理员或超级管理员；
- 只有超级管理员可以授予或调整管理员、超级管理员角色；
- 管理员角色与超级管理员角色互斥，部门调整不会自动改变已有角色。
- 系统至少保留一个启用中的超级管理员；超级管理员不能禁用、降级或删除当前登录账号。

### 3.3 公开项目普通用户（非项目创建人）资产权限

- 可以查看公开项目内的全部资产；
- 可以新增系统、版本、需求、测试用例、Bug 和遗留项；
- 新增资产归当前用户；
- 可以编辑、删除和进行本人资产的常规流程操作；
- 不能编辑、删除或批量处理他人资产；
- 批量操作同时包含本人和他人资产时，不执行该批量操作；
- “全部删除”只处理本人创建的资产。

### 3.4 Bug 流程

- Bug 创建人可以维护本人创建的 Bug；
- 被指派的处理人可以执行“解决”操作，但不能因此编辑或删除该 Bug；
- 验证人可以执行“验证”操作，但不能因此编辑或删除该 Bug；
- 项目创建人可以处理本人项目的全部 Bug 流程；
- 超级管理员可以处理全部公开和私有项目的 Bug 流程；
- 管理员可以处理公开项目的全部 Bug 流程，以及本人创建的私有项目 Bug 流程。

| 管理员 | 使用 AI 补全、AI 合并和 AI 生成测试用例 |
| 普通用户 | 使用 AI 补全、AI 合并和 AI 生成测试用例 |

- AI 生成内容在用户预览并确认后保存；
- 使用 AI 不会获得项目结构、他人资产或项目配置的管理权限。

### 4.3 普通用户 API 测试操作

以下操作规则针对非项目创建人的普通用户；普通用户本人创建的项目按项目创建人权限执行。

- 可以查询公开项目的接口、接口集、接口用例和参数集列表；
- 可以查看执行集列表、测试报告列表、统计信息和报告结果汇总；
- 不能查看接口、用例、环境、报告步骤、请求响应、断言差异和发送日志等详情；
- 不能查看参数集详情；
- 不能新增、编辑、删除或排序接口测试资产；
- 不能导入接口文档并保存到项目；
- 不能修改环境、参数集或项目配置；
- 不能调试接口、运行接口用例或运行执行集；直接调用后端入口时统一返回“权限不足”，不会发出外部请求或生成报告；
- 不能查看环境详情，即使该环境所属项目公开；
- 不能获取或使用非本人创建项目的环境 Token；
- 不能在非本人创建项目中使用 Token 预览；
- 不能复制 API 测试项目；
- 不能发送或删除报告。

普通用户在本人创建的公开或私有 API 测试项目中，可以按项目创建人的权限使用项目环境 Token 和 Token 预览。

## 6. 敏感信息

以下信息不得向普通用户返回明文：

- Authorization、Cookie、Token、API Key 和密码；
- 环境变量中的密钥和认证值；
- Webhook 密钥及其他通知渠道凭证；
- 请求头、请求体、响应体中标记为敏感的内容；
- 能够直接调用外部系统的完整认证配置。

项目公开只代表业务数据可以查询，不代表认证信息、环境凭证和通知凭证可以查询或使用。

管理员可以查看其有权访问的公开项目和本人创建的私有项目中的敏感字段明文；管理员不能通过角色权限查看其他用户的私有项目。超级管理员可以查看全部项目的敏感字段明文。

## 9. 权限不足提示

已登录用户执行无权限操作时，统一使用现有的“权限不足”提示，由后端返回并由前端统一展示一次。未登录或登录失效继续使用登录提示；参数校验、业务校验和资源不存在继续使用对应的业务提示。

用户直接访问无权访问的私有项目或私有资源时，返回“权限不足”，不返回“项目不存在”，避免暴露私有项目或资源是否存在。
