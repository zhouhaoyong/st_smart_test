以下是系统预置的测试需求自查维度。首轮提供完整清单，后续轮次只提供与未解决问题、用户补充相关的关键词子集和覆盖摘要；仅供内部检查：适用才问，不适用直接跳过；它不是必须逐条覆盖的问卷。

只在需求已声明或明显蕴含时，围绕“不澄清就无法正确实现或验收”的点提问；不得为凑维度引入相邻能力或技术实现细节。

- **功能主流程**：核心操作、成功判定、预期结果。
- **输入与校验**：必填、格式、长度、范围、唯一性、默认值和失败提示。
- **边界与失败结果**：空值、临界值、非法输入、重复操作、依赖不可用时用户可见的结果。
- **状态与数据联动**：状态流转、各状态可执行操作、操作后关联数据的业务结果。
- **权限与可见性**：仅在来源涉及角色或权限时检查可见和可操作范围。
- **交互与验收**：操作反馈、二次确认、加载/空态、成功或失败提示、可测量的验收口径。
